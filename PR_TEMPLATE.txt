# Pull Request: CreditSmart React - Implementación Completa

##  Resumen

Esta solicitud de extracción completa la migración de CreditSmart a una aplicación **dinámica con React**, implementando todos los requisitos de la actividad:

 **Catálogo dinámico** con 8 productos crediticios  
 **Componente reutilizable** CreditCard  
 **Simulador** con búsqueda y filtros funcionales  
 **Formulario** de solicitud con validaciones y cálculos  
 **Estilos profesionales** y totalmente responsivos  
 **8 commits** descriptivos y organizados  

---

##  Cambios Principales

### 1 Datos Expandidos (8 Créditos)
- **Archivo:** src/data/creditsData.js
- Catálogo expandido de 2 a 8 productos
- Datos organizados para renderizado dinámico con .map()

### 2 Sistema de Estilos Profesional
- **Archivo:** src/main.css
- 545 líneas de CSS moderno y profesional
- Variables de color con identidad visual clara
- Diseño responsivo: Desktop  Tablet  Mobile
- Componentes: navbar, cards, forms, alerts, buttons

### 3 Componentes Reutilizables

#### CreditCard.jsx
- Tarjeta individual de crédito
- Props: credit object
- Formateo de moneda (COP)
- Hover effects y sombras

#### Navbar.jsx
- Navegación sticky
- Gradiente profesional
- Links a las 3 páginas
- Responsive en mobile

### 4 Páginas Funcionales

#### Home.jsx
- Grid responsivo de créditos
- Renderizado dinámico con .map()
- 8 tarjetas visibles

#### Simulador.jsx 
- **Búsqueda en tiempo real** por nombre
- **Filtro por monto** (rango min-max)
- **Ordenamiento por tasa** de interés
- Mensaje "No hay créditos disponibles"
- Botón "Limpiar Filtros"
- useMemo para optimización

#### Solicitar.jsx 
- **Validaciones** en tiempo real
- **6 campos:** tipo de crédito, nombre, email, teléfono, monto, plazo
- **Cálculo de cuota mensual** con fórmula de amortización
- **Resumen visual** antes de enviar
- **Array en memoria** para guardar solicitudes
- **Historial** de solicitudes
- Mensaje de éxito
- Limpieza automática del formulario
